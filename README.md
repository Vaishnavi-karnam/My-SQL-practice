📂 Projects Included

1. Employee Data Analysis

A practice dataset containing employee details such as department, job title, salary, city, joining date, experience, and performance rating.

SQL concepts practised:

SELECT and DISTINCT

WHERE and ORDER BY

Aggregate functions: COUNT, SUM, AVG, MIN, MAX

GROUP BY and HAVING

Subqueries

Window functions and ranking

2. E-commerce Sales Analysis

A sales dataset containing order details, customer names, products, categories, quantities, prices, discounts, payment methods, cities, order dates, and order statuses.

SQL concepts practised:

Filtering and sorting sales data

Calculating order values and revenue

Analysing sales by product, category, and city

Identifying popular payment methods

Monthly sales analysis

Revenue calculations after discounts

Aggregate functions and business insights
